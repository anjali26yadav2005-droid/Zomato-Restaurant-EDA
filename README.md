# Zomato Restaurant Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Zomato restaurant dataset.

## Objectives
- Explore the restaurant dataset
- Clean and inspect the data
- Analyse restaurant trends
- Create meaningful visualizations
- Identify key insights

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
- Data inspection
- Data cleaning
- Restaurant analysis by city
- Cuisine analysis
- Rating analysis
- Votes analysis
- Table booking analysis

## Visualizations
The project includes:
- Bar chart
- Line chart
- Histogram
- Scatter plot
- Pie chart
- Heatmap

## Dataset
Zomato Restaurant Dataset from Kaggle.

## Conclusion
The analysis provides insights into restaurant distribution, cuisines, ratings, customer votes, and table booking patterns.
